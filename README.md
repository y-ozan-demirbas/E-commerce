E-commerce Web Application (React | Redux | Vite)

This project is a modern e-commerce web application built with React and Vite.
The goal is to provide a platform where users can browse products, add or remove items from the shopping cart, and manage their shopping experience efficiently.

🚀 Features
🛍️ Product Management

Display products with images, titles, prices, and color options

View detailed information for each product

🛒 Shopping Cart

Add and remove products from the cart

Automatically calculate the cart total

📱 User Experience

Responsive design for mobile, tablet, and desktop devices

Centralized state management using Redux

🔍 Development & Testing

Products can be managed locally or fetched from an API

Fast development with Vite’s hot module replacement

🛠️ Technologies

Frontend: React, Vite, CSS

State Management: Vanilla Redux

Routing: React Router

Development Tools: ESLint for code quality, Vite for fast development

🔑 Key Components / Features (Examples)

ShopCards.jsx → Create product cards

ShopCardHolder.jsx → Display products with pagination

Redux Store → Centralized management of products, cart, and user interactions
